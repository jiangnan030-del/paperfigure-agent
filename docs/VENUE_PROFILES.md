# Venue profiles and source discipline

Venue profiles are **versioned interpretations**, not official templates and not promises of acceptance. The live instructions and supplied LaTeX/Word template always prevail.

## Nature Machine Intelligence

Official source: <https://www.nature.com/natmachintell/submission-guidelines/aip-and-formatting> (accessed 2026-08-10).

Implemented checks/metadata include the official 180 mm maximum width, minimum 300 dpi for panels, 5–7 pt sans-serif labels, editable labels/error bars, scale-bar use, statistical legend details, and source-data encouragement. The 3.50-inch single-column width is a project working default, not an official requirement quoted by the journal.

## ICML 2026

Official sources:

- <https://icml.cc/Conferences/2026/AuthorInstructions>
- <https://media.icml.cc/Conferences/ICML2026/Styles/example_paper.pdf>

The profile records vector preference for plots, 0.5 pt minimum line thickness, no title inside the artwork, named axes, labeled components, captions below figures, and accessibility review. Width values are working defaults inferred for testing; compile in the official template before submission.

## NeurIPS 2026

Official sources:

- <https://neurips.cc/Conferences/2026/CallForPapers>
- <https://neurips.cc/Conferences/2026/PaperInformation/StyleFiles>

The profile records legibility, reproduction-safe lines, captions below figures, grayscale legibility, and use of the current style files. The 5.50-inch width is a working rendering target and must be checked in the official template.

## ECCV 2026

Official sources:

- <https://eccv.ecva.net/Conferences/2026/SubmissionPolicies>
- <https://github.com/paolo-favaro/paper-template>

The profile records the 2026 LNCS requirement, line-art and halftone resolution guidance, 2 mm lettering, captions below figures, and the prohibition on absolute coordinates. The 4.80-inch width is a working target; the official 2026 author kit is authoritative.

## Update rule

Each profile must store source URLs, access date, status, and the distinction between quoted requirements and project defaults. Changing a requirement requires a source diff and a regression test. Do not invent a rule from venue reputation or copy one venue's settings into another.
